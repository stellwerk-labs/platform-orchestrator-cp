# Orchestrator Control Plane v3.1.1

This maintenance release updates the Go toolchain and dependencies while
preserving the v3.1.0 API, permissions and database schema.

## Security and compatibility

Official builds use Go 1.26.10, including the certificate verification fix for
[CVE-2026-111943](https://pkg.go.dev/vuln/GO-2026-6809). HTTP, cryptography,
compression, OpenAPI and telemetry dependencies are updated.

OpenAPI reference descriptions use valid composition without changing JSON
fields or wire values. Generated middleware retains authentication and
permission checks. The SDK source now requires Go 1.26.10 and preserves the
published authorization and Pin action constants, including `Prepare`, `Begin`
and `UserIdHeaderScopes`. SDK module tags are published separately from the
application tag.

Normal CI checks source dependencies and the compiled server for reachable
known vulnerabilities. Release binaries retain linker symbols for this scan;
DWARF debug information remains omitted. Docker build contexts exclude direnv
and local environment state.

## Upgrade and recovery

The coordinated application patch set is Control Plane 3.1.1, Data Plane 4.0.1,
IAM 2.5.1 and Console 1.4.1. Use verified public artifacts for the selected set.
This patch adds no database migration. Back up application databases and
configuration before upgrading. Retain the v3.1.0 schema and use a compatible
application revision or forward repair; database Down migrations are not a
recovery procedure.

This release does not update the Runner, plugin runtime or external services.
Their separately documented security holds remain in effect.

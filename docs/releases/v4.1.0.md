# Control Plane 4.1.0

Module catalogue lists now return optional `has_proposed` and `default_verified` summaries to callers with `module.version.read`. The summaries cover complete version history, not just its first page. Core-only readers retain catalogue access without receiving version metadata. Verification itself is unchanged and currently supports only `unverified`.

Set `DATABASE_SSLMODE` to require PostgreSQL TLS. The default remains `disable`. The driver accepts its standard modes; `require` encrypts without plaintext fallback, while `verify-full` also verifies the server identity with the configured CA. Standard `PGSSLROOTCERT` and client certificate variables remain driver-owned. Restart the service after changing startup configuration.

The release workflow stores the original qualified OCI archive and evidence before publication. RC and stable publishers validate and reuse those bytes, preserving the original producer attempt on partial reruns. Existing draft/image collisions refuse replay, and an old stable publisher cannot replace a newer `latest` release.

No database migration or existing API removal is introduced. The new Console filters require this catalogue-summary support; existing clients continue to work. See the coordinated Helm release for matching qualified image pins.
